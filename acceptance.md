# Приёмка: Шаг 7b.1 — долечить модуль `todos`

Чекбоксы ставит **приёмщик**, не исполнитель. Пункт закрывается своим доказательством, а не пересказом шага.

Прогон тестов: `npm --prefix web test`. Сборка: `npm run build`.

## Безопасность (принцип 0)

- [ ] Кавычка в названии задачи не разрывает HTML-атрибут
  WHEN задача с названием `x" onfocus="alert(1)" autofocus="` приходит из API и рисуется в списке
  THEN у элемента `<input class="todo-app__checkbox">` нет атрибутов `onfocus` и `autofocus`, а весь payload лежит внутри значения `aria-label` как текст

- [ ] Экранирование закрыто в одной точке, а не у одного вызова
  WHEN в разметку модуля подставляется любая строка, пришедшая от пользователя (название в тексте карточки, название в `aria-label`, `id` в `data-id`)
  THEN каждая из них проходит через общую функцию экранирования, и добавление нового места вставки не требует своего экранирования

- [ ] Угловые скобки по-прежнему не исполняются
  WHEN название задачи содержит `<script>alert(1)</script><img src=x onerror=alert(2)>`
  THEN в документе нет элементов `script` и `img` из этого названия, а текст виден пользователю как есть

## Отмена запросов и утечки

- [ ] `destroy()` реально отменяет запрос, а не только взводит флаг
  WHEN `init()` запустил загрузку списка и до ответа сервера вызван `destroy()`
  THEN объект, переданный в `fetch`, имеет `signal.aborted === true`, и промис запроса отклоняется

- [ ] Слушатель фильтров снимается вместе с остальными
  WHEN `init()` и `destroy()` вызваны подряд десять раз на одном контейнере
  THEN клик по кнопке фильтра после последнего `destroy()` не вызывает ни одного обработчика модуля

- [ ] Переключение модулей не копит отсоединённые узлы
  WHEN в браузере переключиться с `todos` на другой модуль и обратно десять раз
  THEN в devtools → Memory → Detached elements число отсоединённых узлов не растёт линейно с числом переключений
  (не проверено живьём — закрывается хозяином, агент браузер не запускает)

- [ ] Таймер сообщения об ошибке не переживает выгрузку
  WHEN показано сообщение об ошибке и сразу вызван `destroy()`
  THEN отложенный колбёк не обращается к элементам модуля после выгрузки

## Соответствие spec.md §2

- [ ] Модуль `todos` показывает только четыре статуса
  WHEN в базе есть задачи со статусами `backlog` и `archived`
  THEN они не видны ни под одним фильтром и не входят в счётчик «Все (N)»

- [ ] Счётчик «Все» сходится с суммой остальных счётчиков
  WHEN список загружен с любым набором задач
  THEN число в «Все (N)» равно сумме «К выполнению», «В работе», «На проверке» и «Завершено»
