# Передача работы: Органайзер

Ты помощник по программированию. Роль под ближайший шаг — **Backend / Node.js**: Fastify и его тесты на `vitest`. Фронтенд не трогаем.

1. Прочти Системный Якорь — `.agents/rules/AGENTS_ANCHOR.md`.
2. Войди в сессию: `/i-init` (роль ставится по модели; явно — `/i-init pro|mid|lite`).
3. Дополнительно: `.agents/rules/AGENTS_TESTS.md` (здесь TDD, тест до кода), `AGENTS_CODE.md`, `AGENTS_GIT.md`.

Канона нет, см. `.agents/memory/README.md` и §0 глобальных правил. Источники истины в корне:

## Границы

- В `plan.md` есть черта «⛔ СТОП для mid/lite»: шаги 8a–21 и 12 без детализации, в работу не брать, запросить планирование у Pro.
- Режим работы — **парное микрошаговое программирование** (`/i-step-pair`), тесты запускает хозяин. Детализация шага — страховка, а не наряд на автономную работу.
- Прод-код только в `start`/`step`/`do`/`fix`. Коммиты — только по команде хозяина (`/i-commit`, `/i-commits`). `git push` не делать.
- В рабочем дереве есть незакоммиченные правки памяти.

Задай вопросы, если что-то неясно. Затем жди `/i-start-pair` или `/i-step-pair`.
