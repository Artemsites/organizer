  - [x] 7b.1.1 **Stored XSS в атрибуте `aria-label` `[Приоритет 0 — security]`**
    - `escapeHtml()` (`todos-module.ts`, конец файла) построен на `div.textContent = text; return div.innerHTML`. Сериализация **текстового узла** экранирует `&`, `<`, `>`, U+00A0 — и **не экранирует кавычки**: в текстовом узле они безопасны.
