# GLOSSARY.md: Единый глоссарий терминов

- **Ядро (Core / Server)** — центральный демон на Node.js (Fastify, SQLite, croner), обеспечивающий хранение состояния, планировщик задач и REST API.
- **CLI-Воркер (Client Worker)** — консольное приложение и системный агент на macOS/Linux (`organizer/cli`), исполняющий команды с доступом к локальной ОС (bash, `zx`, `puppeteer-core`).
- **Web UI** — браузерный графический интерфейс органайзера (`organizer/web`), работающий с ядром по REST API на чистом DOM API + SCSS.
- **Split-плагин** — модуль расширения, разделенный на манифест (`manifest.yml`), серверную часть (`server/entry.ts`), клиентскую автоматизацию (`client/entry.ts`) и веб-компонент (`web/entry.ts`).
- **Синхронизация (Sync)** — двусторонний обмен состоянием между ядром и подключенными клиентами по протоколу `/api/v1/sync` с отслеживанием `lastSyncAt`.
