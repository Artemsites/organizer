# Канон этого проекта не ведётся

Источники истины лежат в корне репозитория:

- `spec.md` — требования, архитектура, стек, приоритеты модулей. Не редактировать без разрешения хозяина.
- `plan.md` — шаги, порядок, тесты приёмки.
- `memory.md` — решения с обоснованием (ADR) и референсы архитектуры.
- `issues.md` — техдолг, находки вне Scope, открытые вопросы.
- `report.md` — отчёты о выполненных фичах (появится по мере работы).
- `README.md` — как запустить, конфигурация, частые ошибки.

Причина: один репозиторий, один поток работ, один `spec.md`. Канон сводит память многих задач — сводить нечего, а вторая копия фактов расходится с первой. Так и вышло: 2026-09-14 `PROJECT.md` разошёлся со `spec.md` по статусам задач, драйверу браузера и убранному модулю дневника.

Правило: **один факт — одно место**. Новый файл памяти заводится, когда в него есть что положить сегодня.
