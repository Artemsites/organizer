# AUDIT.md: Журнал техдолга и отложенных задач

## Отложенные задачи и инфраструктура
- **Деплой на Beget (Passenger, cron fallback)**: Вынесен в финальный Шаг 9 плана. Требует проверки поддержки Node 22.5+ и долгоживущих процессов Passenger на виртуальном хостинге.
- **Интеграция Chromium для плагина веб-автоматизации**: Плагин `browser-automation` потребует локально установленного Chrome или загрузки `chrome-headless-shell` через puppeteer.

## 2026-09-14: Находки ревью плана и Шага 7.0

### Уязвимости (принцип 0), заведены шагами в локальный plan.md
- **Произвольное выполнение кода на машине хозяина.** `cli/src/plugin-loader.ts:41` (`loadFromCode`) скачивает JS с сервера и делает `import()` в основном процессе Node, плюс выдаёт плагину `exec` через `zx`. Подписи нет, песочницы нет, whitelist нет. Скомпрометированный или подменённый сервер = любой код на Mac. Блокер всех плагинов, заведён как Шаг 16.5 (песочница). Референсы: VS Code extension host, разрешения в манифесте Joplin.
- **Сервис открыт в локальную сеть с публично известным секретом.** `server/src/index.ts` слушает `0.0.0.0`, `server/src/auth.ts` держит `DEFAULT_TOKEN = 'organizer-secret-token'` фолбэком. Шаг 7.0.1.
- **Записи без валидации.** `POST`/`PATCH /api/v1/tasks` пишут в SQLite любую строку (`{status:'lol'}` сохранится); `zod` в зависимостях есть, но не используется. Шаг 7.0.2.
- **Инъекция AppleScript.** Текст напоминания приходит с сервера и уйдёт в `osascript` — передавать аргументом/через stdin, не склейкой строки. Тот же запрет на `zx`-вызовы плагинов. Шаг 8c.
